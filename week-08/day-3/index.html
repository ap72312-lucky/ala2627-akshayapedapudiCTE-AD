What am I learning?

Yesterday your click changed the page, but it changed it the same way every time. Today the page remembers.

A variable is a named box that holds a value. let count = 0; makes a box called count with 0 in it. A function is a named set of instructions that runs when you call it. Put them together — a click runs a function, the function changes the variable, then shows the new value — and the page is keeping track of something between clicks. That is how a like button knows it is on 12.

One rule saves most of today's problems: create the variable at the top of script.js, not inside the function. Inside the function it gets rebuilt from scratch on every click, so a counter shows 1 forever.
